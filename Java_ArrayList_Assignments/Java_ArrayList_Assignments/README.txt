Java ArrayList Assignments

This ZIP contains six independent Java programs:
1. Employee ID Management
2. Shopping Cart
3. Product Price List
4. Character List
5. Customer Management System
6. Online Order Management System

How to run:
1. Extract the ZIP file.
2. Open a terminal or command prompt in this folder.
3. Compile a program, for example:
   javac Assignment1_EmployeeIDManagement.java
4. Run it:
   java Assignment1_EmployeeIDManagement

Repeat the compile and run steps for any other assignment.
Java JDK must be installed.
